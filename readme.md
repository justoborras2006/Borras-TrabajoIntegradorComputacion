# Trabajo Integrador - Computación

## Descripción

Este proyecto corresponde al Trabajo Práctico Integrador de Computación.

El objetivo es implementar un flujo de trabajo con Git, GitHub y GitHub Actions, incorporando pruebas automatizadas, Pull Requests y protección de la rama principal.

El sistema trabaja con archivos CSV de compras de supermercado y permite procesar información agrupada por sucursal y producto.

## Funcionalidades principales

- Lectura de archivos CSV.
- Procesamiento de compras por sucursal.
- Cálculo de unidades vendidas por producto.
- Cálculo de importes totales.
- Identificación del producto con mayor importe.
- Identificación del producto con menor importe.
- Organización del código en funciones para facilitar el testing.
